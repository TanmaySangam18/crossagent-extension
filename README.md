# Crossagent.si — Chrome Extension

> Type `@claude`, `@gemini`, or `@all` inside any AI chat. All your agents respond in a sidebar — no tab switching, no API keys, no repeating yourself.

## What it does

Crossagent.si is a Chrome extension that lets you tag any AI from inside any AI's chat interface:

- **Native routing** — uses your own logged-in accounts. No API keys. No token limits.
- **7 platforms** — Claude, ChatGPT, Gemini, Perplexity, Grok, Mistral, Copilot
- **@all broadcast** — asks every agent simultaneously, synthesized into one answer
- **Cross-session memory** — Engram remembers facts and preferences across every session

## Install

1. Download the latest release zip from the [Releases page](../../releases)
2. Unzip the file
3. Open Chrome → `chrome://extensions`
4. Enable **Developer mode** (top right)
5. Click **Load unpacked** → select the unzipped folder

## Usage

- Type `@claude`, `@gemini`, `@chatgpt`, `@grok`, `@perplexity`, `@mistral`, `@copilot`, or `@all` at the start of any message inside any AI chat
- Press **Alt+Shift+C** to toggle the Crossagent sidebar panel
- The target AI must be open in a browser tab — Crossagent routes natively through your existing session

## Requirements

- Chrome or Chromium-based browser
- The target AI platform open in a tab and logged in

## Memory (Engram)

For persistent cross-session memory, sign in at [crossagent.si](https://crossagent.si) and paste your User ID into the extension popup. Your conversations are distilled into atomic facts and recalled automatically.

## Privacy

Native routing is 100% local — no data touches our servers. See the full [Privacy Policy](https://crossagent.si/privacy).
